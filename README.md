<h2 id="english">🇬🇧 English</h2>

A highly advanced, lightning-fast web application that transliterates Mongolian text between Latin (Galig) and Cyrillic. Powered by a custom offline NLP engine, it intelligently predicts internet slang, shortcuts, and correctly applies suffix/vowel harmony rules without relying on external APIs.

### 🌟 Key Features
- **🧠 Smart NLP Prediction:** Understands common internet abbreviations (e.g., `ymr ch ugiig yrn bl` -> `ямар ч үгийг ер нь бол`).
- **🧩 Morphology & Suffix Analysis:** Intelligently separates root words and suffixes for accurate translation (e.g., `ugiig` -> `ug` + `iig` -> `үгийг`).
- **🔄 Two-Way Conversion:** Latin to Cyrillic & Cyrillic to Latin.
- **💾 Auto-Save & History:** Automatically saves your progress and keeps a history of the last 5 texts.
- **📄 Import & Export:** Upload `.txt` files and export your converted text instantly.
- **🌓 Dark / Light Mode:** Beautiful Apple-inspired Glassmorphism UI.
- **🌍 Bilingual UI:** Switch seamlessly between English and Mongolian interfaces.
- **📊 Live Counter:** Real-time word and character counting.

### ⌨️ Keyboard Shortcuts
- `Ctrl + Shift + S` : Swap translation direction.
- `Ctrl + Shift + C` : Copy the converted result.

### 🚀 How to Run
No installation or server is required! 
1. Download or clone the repository.
2. Open `index.html` in any modern web browser (Chrome, Safari, Edge, etc.).
3. Enjoy offline, instant translations!

<h2 id="монгол">🇲🇳 Монгол</h2>

Монгол хэлний Латин (Галиг) болон Кирилл үсгийн хооронд хөрвүүлэх зориулалттай, маш хурдан, ухаалаг вэб аппликэйшн. Гадны API (интернэт) ашиглахгүйгээр хөтөч дээр шууд ажилладаг бөгөөд хүмүүсийн түгээмэл ашигладаг товчлол, үгсийн үндэс, дагавар нөхцөлийг автоматаар таньж, эгшиг зохицуулан хөрвүүлэх "Ухаалаг Таамаглагч" хөдөлгүүртэй.

### 🌟 Үндсэн боломжууд
- **🧠 Ухаалаг таамаглагч (NLP):** Интернэтэд ихэвчлэн товчилж бичдэг үгсийг танина (жишээ нь: `ymr ch ugiig yrn bl` -> `ямар ч үгийг ер нь бол`).
- **🧩 Дагавар, нөхцөл таних:** Үгийн үндэс болон дагаврыг салгаж, эгшиг зохицох дүрмээр ухаалгаар хөрвүүлнэ (жишээ нь: `ugiig` -> `ug` + `iig` -> `үгийг`).
- **🔄 2 чиглэлт хөрвүүлэлт:** Латин -> Кирилл, Кирилл -> Латин.
- **💾 Түүх болон Автомат хадгалалт:** Бичиж буй текстийг автоматаар хадгалж, сүүлд хөрвүүлсэн 5 текстийн түүхийг харуулна.
- **📄 Файл оруулах / Татах:** Урт `.txt` файл оруулж хөрвүүлээд, буцаагаад файл хэлбэрээр татаж авах боломжтой.
- **🌓 Dark / Light горим:** Нүдэнд ээлтэй, орчин үеийн Glassmorphism дизайнтай.
- **🌍 Хос хэлний сонголт:** UI-г Монгол болон Англи хэлээр ашиглах.
- **📊 Амьд тоолуур:** Бичиж буй үг болон тэмдэгтийн тоог бодит хугацаанд тоолно.

### ⌨️ Гарын товчлолууд (Shortcuts)
- `Ctrl + Shift + S` : Хөрвүүлэх чиглэлийг солих (Swap).
- `Ctrl + Shift + C` : Хөрвүүлсэн үр дүнг хуулах.

### 🚀 Хэрхэн ажиллуулах вэ?
Ямар нэгэн програм суулгах эсвэл сервер асаах шаардлагагүй!
1. Файлуудаа татаж авна.
2. `index.html` файлыг хүссэн хөтөч дээрээ (Chrome, Safari, Edge г.м) нээхэд л шууд ажиллана.
3. Интернэтгүй орчинд ч бүрэн ажиллах боломжтой.
