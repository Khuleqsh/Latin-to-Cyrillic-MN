## <a name="english"></a> 🇬🇧 English

**Live Demo:** [Click here to use the converter](https://khuleqsh.github.io/Latin-to-Cyrillic-MN/)

A web-based tool that automatically converts Mongolian Latin (Galig) text into Cyrillic script in real-time. It also features a smart dictionary to recognize and expand common internet chat shortcuts into full words.

### 🌟 Features
- **Real-time Conversion:** Converts text instantly as you type.
- **Double-Letter Recognition:** Accurately converts multi-character Latin inputs (e.g., `sh` -> `ш`, `ch` -> `ч`, `ts` -> `ц`).
- **Smart Chat Shortcuts:** Automatically expands common Mongolian chat abbreviations (e.g., `bn` -> `байна`, `snu` -> `сайн уу`, `mdq` -> `мэдэхгүй`).
- **Capitalization Aware:** Maintains proper capitalization for sentences and names.
